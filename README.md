## Resumo dos Conceitos Praticados

Durante os desafios, foram praticados conceitos fundamentais de HTML e CSS. Aprendi a estruturar páginas utilizando diferentes tags HTML e a utilizar CSS para modificar o visual, o posicionamento e a organização dos elementos.

As principais dificuldades foram compreender a função de algumas tags e propriedades CSS e organizar corretamente os elementos da página. Também foram praticados conceitos como classes, seletores, propriedades de estilo e estruturação de páginas.
